# QRDrop — QR コードでつなぐ同一ネットワーク内データ転送

PC で起動して表示される QR コードをスマホで読み取るだけで、スマホ ⇔ PC の
ファイル・テキスト転送ができるツールです。スマホ側のアプリは不要
(ブラウザのみ)で、データは**同一ネットワーク(LAN)の外に一切出ません**。

## 動作環境

- PC: Windows 11(サーバ側。Go 1.22+ でビルド)
- スマホ: iOS Safari / Android Chrome の現行版(QR を読み取るだけ)
- 両者が同じ Wi-Fi / LAN に接続されていること

## セットアップと起動

```
winget install GoLang.Go
git clone <repo> && cd qrdrop
go build ./cmd/qrdrop
.\qrdrop.exe
```

- 初回起動時に Windows ファイアウォールの受信許可ダイアログが出たら
  **「プライベートネットワーク」のみにチェックして「許可」**してください。
- 起動すると既定ブラウザで管理ページ(`http://127.0.0.1:8931/admin`)が開きます。
  表示された QR コードをスマホのカメラで読み取ると転送ページが開きます。

## 使い方

| やりたいこと | 操作 |
|--------------|------|
| スマホ → PC | 転送ページでファイルを選んで「送信」。PC の `ダウンロード\QRDrop\` に保存されます |
| PC → スマホ | 管理ページの「共有に追加」にファイル/テキストを入れると、スマホ側の一覧に現れます |
| テキストの受け渡し | 双方向ともテキスト欄から送信。受信側でワンクリックコピー |
| セッションを切る | 管理ページの「セッション終了」。古い QR は即時無効になり、新しい QR が表示されます |

## コマンドラインオプション

| オプション | 既定値 | 説明 |
|-----------|--------|------|
| `-port` | 8931 | 待ち受けポート(使用中なら自動で次を探す) |
| `-dir` | `%USERPROFILE%\Downloads\QRDrop` | 受信ファイルの保存先 |
| `-ttl` | 30m | QR(セッション)の有効期間 |
| `-no-browser` | false | 起動時にブラウザを開かない |

## セキュリティ上の注意(必ずお読みください)

- 通信は **LAN 内の平文 HTTP** です。トークン(推測不能な URL)・
  プライベート IP 検査・有効期限の多層防御で LAN 外や第三者からのアクセスは
  遮断しますが、**同一 LAN 内の盗聴には耐えません**。
  - **公衆 Wi-Fi・共有オフィスの LAN での利用は非推奨**です。
  - 機密性の高いファイルの転送には使わないでください。
  - 自宅の WPA2/WPA3 で保護された Wi-Fi での利用を想定しています。
- **ルーターのポートフォワード(ポート開放)設定は行わないでください。**
  本ツールをインターネットに公開する構成は想定外であり危険です
  (UPnP 等による自動開放は実装していません)。
- 動作ログは `%APPDATA%\QRDrop\logs\` に出力されます(接続元 IP・ファイル名・
  結果のみ。ファイル内容やテキスト本文は記録されません)。

## つながらないとき

- **QR を読んでもページが開かない**: PC とスマホが同じネットワークに
  いるか確認してください。ルーターの **AP アイソレーション**(プライバシー
  セパレータ)が有効な場合、端末間通信が遮断されるため本ツールは使えません。
  ルーター設定で無効化するか、別のネットワークをご利用ください。
- **「セッションが無効です」と出る**: QR の有効期限(既定 30 分)切れです。
  管理ページの新しい QR を読み取り直してください。
- **ファイアウォールのダイアログで「キャンセル」してしまった**:
  Windows 設定 → ファイアウォール → アプリの許可 で qrdrop.exe の
  「プライベート」を許可してください。
- **VPN 使用中・複数サブネット構成**: 接続元がプライベート IP 範囲外と
  判定される場合は接続できません(仕様)。

## 仕様の要点

- 転送データ・共有一覧はメモリ保持のみで、アプリ終了時に消えます。
  ディスクに残るのは受信フォルダへ保存されたファイルだけです。
- 同名ファイルを受信した場合は `名前 (1).拡張子` の形式で連番保存します。
- 1 ファイルの上限は 2GB です。
